# Freight Rate Prediction Challenge

## Objective

Predict `posted_rate` for 12,000 future freight loads and generate the fixed
December 2025 prediction series required by the supplied scorer.

## Dataset

- Training: 48,000 labeled loads from 2025-01-01 through 2025-10-31.
- Validation: 12,000 unlabeled loads from 2025-11-01 through 2025-12-31.
- Target: `posted_rate`.

## Key Data Quality Findings

- No duplicate training rows.
- `weight` contains 300 missing and 292 negative values. Non-positive values
  are treated as missing and imputed with a median fitted on training rows only.
- `market_index` contains 374 missing values, but it is not used by the final
  model.
- The target is right-skewed with a small number of large rates, so MAE is the
  primary model-selection metric.

## Validation Strategy

The hidden set occurs after the training period, so a random split would not
represent deployment. Model selection uses expanding-window temporal folds:
train on all dates before the validation month, then validate on August,
September, and October 2025. Each fold fits its weight-imputation median using
only that fold's training rows.

## Baseline

The domain baseline is:

```text
predicted_rate = distance * quote_signal
```

Its temporal MAE was unstable:

| Validation month | MAE |
| --- | ---: |
| August 2025 | 317.26 |
| September 2025 | 71.75 |
| October 2025 | 413.72 |

## Models Evaluated

| Model | Role in selection |
| --- | --- |
| Quote baseline | Domain reference |
| HistGradientBoosting direct | Nonlinear numeric benchmark |
| HistGradientBoosting residual | Quote-residual benchmark |
| CatBoost direct | Best-performing model family |
| CatBoost residual | Tested but less temporally stable |

Depth 6, 8, and 10 variants, a lower learning rate, and blending with the quote
baseline were also evaluated. The depth-6 direct CatBoost configuration was
selected; further tuning did not show a material benefit.

## Final Model

The final estimator is `CatBoostRegressor` with:

- `iterations=1050`
- `learning_rate=0.05`
- `depth=6`
- `l2_leaf_reg=5`
- `loss_function="MAE"`
- `random_seed=42`

## Final Feature Set

Categorical features:

- `pickup`, `delivery`, `equipment`, `lane`

Numeric features:

- `distance`, `weight`
- `month`, `day`, `day_of_week`, `day_of_year`, `week_of_year`
- `is_weekend`, `days_since_start`
- `day_of_year_sin`, `day_of_year_cos`

## Final Temporal Results

These are the leakage-clean results produced by `python -m src.evaluate`:

| Validation month | MAE | RMSE | R² | Best iteration |
| --- | ---: | ---: | ---: | ---: |
| August 2025 | 92.28 | 613.18 | 0.8271 | 1,396 |
| September 2025 | 107.67 | 617.94 | 0.8354 | 904 |
| October 2025 | 118.18 | 648.34 | 0.8201 | 614 |
| Mean | 106.04 | 626.49 | 0.8276 | 971 |

## Why the Common Feature Set Was Selected

The smaller feature set outperformed the richer configuration in out-of-time
validation, reduced temporal instability, and avoids a training-serving
mismatch. It is available for both the 12,000-row validation set and the fixed
December scenario, unlike the experimental market, quote, and coordinate
features.

## Setup

Run all commands from the repository root. Python 3.11 or newer is recommended.

```bash
python -m venv .venv
```

Activate the environment:

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

```bash
# macOS/Linux
source .venv/bin/activate
```

Install dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Run Temporal Evaluation

```bash
python -m src.evaluate
```

## Train Final Model

```bash
python -m src.train
```

## Generate Validation Predictions

```bash
python -m src.predict
```

## Generate December Predictions

```bash
python -m src.predict_december
```

## Run Official Scorer

```bash
python score.py --predictions outputs/validation_predictions.csv --december-predictions outputs/december_predictions.csv --output-dir scorer_results
```

## Outputs

- `outputs/final_temporal_metrics.csv`
- `models/freight_rate_final.cbm`
- `outputs/validation_predictions.csv`
- `outputs/december_predictions.csv`

The scorer validates the output schemas and fixed December scenario. Final
hidden-set metrics are calculated only after submission.

## Limitations

- Only one year of historical data is available.
- Holiday effects are represented only indirectly through calendar features.
- An MAE objective can under-emphasize rare extreme freight rates.
- Hidden validation labels are unavailable, so reported metrics are limited to
  the chronological development folds.
